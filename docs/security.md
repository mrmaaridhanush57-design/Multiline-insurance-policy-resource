# Security

## Target design

Intended roles:

- **Agent:** quotation and policy activities.
- **Adjuster:** claim handling.
- **Manager:** approval and review.

Expected Salesforce controls include Profiles, Permission Sets, object permissions, Field-Level Security, Sharing Rules, record-level security, and state/territory-based claim access where required.

These are requirements only. Do not claim security is implemented until actual org metadata has been imported and verified.

## Actual implementation

**Not verified.** Verify object/field access, sharing defaults and rules, role hierarchy, and state/territory access behavior against the org before documenting the effective security model.
