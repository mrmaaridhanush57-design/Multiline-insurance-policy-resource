# Demo Script

## Target design

This outline describes a future demonstration of intended functionality; it does not imply those features exist.

1. Introduce the Auto, Property, and Life policy use cases.
2. Demonstrate the intended Auto quotation journey and explain that premium calculation must match verified business logic.
3. Show the intended claim initiation and routing process.
4. Demonstrate adjuster claim visibility, search, and filtering.
5. Walk through the intended approval path for claims over $50,000.
6. Explain role-based access and state/territory restrictions after verifying actual permissions and sharing.
7. Present reports/dashboard metrics supported by the verified implementation.
