# Project Viva / Demo Script

> This is a presentation sequence for a configured demonstration org. The repository itself does not provide a live Salesforce environment or data.

1. Log in to the prepared Salesforce demo org.
2. Show the example Customer Account.
3. Create an Auto Policy.
4. Demonstrate the VIN validation rule.
5. Run the configured Auto quotation flow.
6. Show the premium produced by the approved demo pricing logic. Explain sample rates if still in use.
7. Create a Claim related to the policy and customer.
8. Show claim routing after the Flow is configured.
9. Open the Claims Adjuster Dashboard.
10. Search and filter the claims list.
11. Create a high-value claim with an amount greater than $50,000.
12. Show the Senior Adjuster work item and decision.
13. Show the Department Manager work item and decision.
14. Approve or reject and show the resulting status.
15. Explain role permissions, record sharing, and territory restrictions using verified org behavior.

Do not present a step as working until it has been rehearsed in the live org. If configuration is incomplete, present that step as proposed design.
